# Vishanth K — Flowa-Inspired React Portfolio

React + Vite version of the supplied Flowa-inspired portfolio.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Production build

```bash
npm run build
npm run preview
```

## Project structure

- `src/App.jsx` — React components and portfolio content
- `src/styles.css` — responsive Flowa-inspired styling
- `public/assets/vishanth-cutout.webp` — hero cutout
- `public/assets/vishanth-profile.jpeg` — profile image
- `public/assets/Vishanth-K-Resume.pdf` — downloadable CV
